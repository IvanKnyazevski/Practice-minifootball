# Practice-minifootball
2D mini-football game on Pygame
2D Football Game — это небольшой 2D-спортивный симулятор, разработанный на языке программирования Python с использованием библиотеки Pygame.

Игрок управляет футбольным персонажем на игровом поле и должен забивать мячи в ворота соперника. Все основные графические элементы игры создаются непосредственно средствами Pygame с использованием графических примитивов, поэтому для отображения игрового поля, игроков и мяча не требуются внешние изображения.

Игровые режимы

В программе предусмотрено два основных режима игры:

Одиночная игра — игрок соревнуется с ботом, который самостоятельно выбирает направление движения и пытается атаковать ворота соперника.
Игра для двух игроков — два пользователя могут управлять своими игроками с помощью назначенных клавиш.
Основные механики

В игре реализованы следующие основные механики:

движение игрока вперёд в направлении его текущего положения;
автоматическое вращение игрока при отсутствии команды на движение;
выполнение рывка в выбранном направлении;
взаимодействие игрока с мячом;
движение и физика мяча;
столкновения мяча с игроками и границами игрового поля;
проверка пересечения мячом линии ворот;
подсчёт забитых голов;
пауза и анимация после забитого гола;
экран победителя после достижения трёх голов;
анимированный заголовок «ПОБЕДИТЕЛЬ»;
возможность повторить матч или вернуться в главное меню;
несколько уровней сложности бота;
настройка управления и громкости.
Управление

Управление осуществляется с помощью назначенных клавиш.

В процессе игры:

клавиша управления игроком — движение/рывок в текущем направлении;
ESC — возврат в главное меню.

В режиме двух игроков каждый игрок использует свою назначенную клавишу управления. Клавиши можно изменить в настройках игры.

Бот

Противник управляется встроенным искусственным интеллектом.

При удалении от мяча бот сначала стремится приблизиться к нему. После сближения бот переходит к позиционированию относительно мяча и ворот соперника. Для выполнения атаки бот оценивает расстояние до мяча и направление движения, после чего выполняет рывок в сторону ворот противника.

Для бота предусмотрено несколько уровней сложности.

Игровое поле и графика

Игровое поле, ворота, игроки, мяч и элементы интерфейса создаются программно с помощью возможностей библиотеки Pygame.

Игрок представлен в виде круга с маркером направления. Мяч отображается в виде белого круга с элементами чёрного цвета, имитирующими футбольный мяч. Игровое поле также формируется программно без использования внешних графических файлов.

Экран победителя

Матч завершается после того, как один из игроков забивает три гола.

После завершения матча отображается экран победителя с:

анимированным заголовком «ПОБЕДИТЕЛЬ»;
цветом победившей команды;
результатом матча;
кнопкой возврата в главное меню;
кнопкой повторного запуска игры.
Требования

Для запуска программы необходимы:

Python 3.x;
библиотека Pygame.
Установка
Установите Python 3 с официального сайта Python.
Откройте командную строку или терминал.
Установите библиотеку Pygame:
pip install pygame
Запуск

После установки необходимых компонентов перейдите в папку с проектом и выполните:

python soccer_game.py

После запуска откроется главное меню игры, из которого можно выбрать режим игры и перейти к настройкам.

Структура проекта
